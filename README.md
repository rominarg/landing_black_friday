# Landing Black Friday - Electrónica

## Descripción

Landing page de un negocio de electrónica desarrollada con HTML, CSS y JavaScript. El proyecto está enfocado en la presentación de productos con un diseño moderno, responsive y optimizado para dispositivos móviles.

## Demo

GitHub Pages: https://rominarg.github.io/landing_black_friday/

## Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)

## Características

- Diseño responsive adaptable a mobile y desktop  
- Sección de productos  
- Banner principal promocional  
- Interacciones básicas con JavaScript  
- Optimizado para carga rápida  

## Objetivo del proyecto

Este proyecto fue creado como práctica de desarrollo front-end, simulando una landing comercial enfocada en campañas de ventas tipo Black Friday.
